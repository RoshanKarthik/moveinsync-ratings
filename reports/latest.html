  • Tagging: 10,311 of 10,311 reviews since Jan 2023 are tagged with issues from a 33-code taxonomy built from the employee journey. Models: nvidia/nemotron-3-ultra-550b-a55b@nothink, nvidia/nemotron-3-super-120b-a12b@nothink — each review is tagged by every model and an issue counts when most of them agree (average agreement 100%).
  • Accuracy on 120 held-out, labelled reference reviews: main issue correct 99% (95% CI 95%–100%), tag precision 99%, recall 90%.
  • Statistics: shares carry 95% Wilson intervals; changes use a two-proportion z-test; release comparisons are Bonferroni-corrected. Dates are India time.
  • Refresh: double-click refresh.bat or run uv run ratings refresh. Only new or edited reviews are downloaded and tagged.
